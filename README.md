# SongDao

SongDao, displayed as **Sống Đạo**, is a local-first Catholic daily practice app that turns the liturgical calendar into one concrete action for today.

## Beta MVP

The beta ships the smallest loop that can create daily retention:

1. Today screen with liturgical context, one daily action, reading references, Important Mass, completion, and private note.
2. Local-first database for calendar days, celebrations, reading references, action rules, daily actions, action logs, settings, churches, Mass times, and widget snapshots.
3. Minimal Vietnamese seed content pack that works offline.
4. iOS widget snapshot showing today's context and action.
5. Local reminder notifications that deep link back to Today.
6. Basic parish selection and next Important Mass display.
7. Gentle private progress from local action logs.

## Explicit Non-goals

The beta does not include a full Bible, full breviary, social network, AI priest/confessor, livestream Mass platform, public faith score, account system, payment, Mass attendance proof, or full map-based church finder.

The primary build path remains:

> Today -> completion -> widget snapshot
