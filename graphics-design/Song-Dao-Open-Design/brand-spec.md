## Layout Posture

- Start with a polished hero that immediately shows the product, not abstract brand language.
- Use a visible process/progress rhythm: brief -> direction -> todo -> preview.
- Favor screenshot-led proof blocks with rounded media and restrained dark overlays.
- Keep interaction states calm: thin borders, clear focus rings, compact primary actions.
- Use color as a guide rail and confirmation signal, not as page-wide decoration.
